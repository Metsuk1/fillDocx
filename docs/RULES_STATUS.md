# Статус 51 правила

Обозначения:
- **Код** — детерминированная реализация, результат не зависит от LLM, есть автотест.
- **Карта** — реализовано через карту шаблона (якорь, слот, `formed`, `clause_rules`, `rewrites`, порядок органов).
- **LLM** — правило передано модели в промпте (`notes` органа); результат проверяется кодом
  (цитата, числа, новые слова), но формулировку строит модель. Нужна проверка на реальных диктовках.
- **Черновик** — карта шаблона составлена по правилам без исходного пустого шаблона; сверить якоря.

## Общие требования (§3, §8–§15 правил)

| Требование | Как реализовано |
|---|---|
| Нет технического мусора в Word | В документ пишутся только операции движка правил; предупреждения — в окне и журнале |
| Исходные абзацы и альтернативы шаблона не удаляются | Запись только добавляет run-ы и абзацы; удаление не реализовано намеренно |
| Ф.И.О., контраст, доза, дата исследования не меняются | Пишется только поле даты рождения, и только если оно пустое |
| Числа привязаны к органу, а не к ближайшему слову | Слоты органа в схеме LLM + проверка, что число есть в цитате этого органа |
| Поздние дополнения в свой абзац | Порядок вставок — по порядку органов шаблона; дополнения после заключения возвращаются в описание |
| Посторонние разговоры | Помечаются LLM как `offtopic`, в Word не попадают, видны в окне с меткой времени |
| Неуверенное — не вписывать | Проверка источника отбрасывает факт и показывает его в окне |
| Документ не готов до подтверждения | Статус `needs_review` → `confirmed` только вручную; подтверждение привязано к хешу файла |
